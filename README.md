# 🧮 Calculadora JS

Uma calculadora web moderna, responsiva e interativa criada com HTML, CSS e JavaScript puro.

## ✨ Características

- ✅ **Interface Moderna** - Design minimalista com gradientes bonitos
- ✅ **Responsiva** - Funciona perfeitamente em desktop, tablet e mobile
- ✅ **Todas as Operações** - Adição, subtração, multiplicação e divisão
- ✅ **Suporte a Teclado** - Digite diretamente no seu teclado
- ✅ **Sem Dependências** - Apenas HTML, CSS e JavaScript puro
- ✅ **Validação** - Proteção contra erros e operações inválidas
- ✅ **Animações Suaves** - Transições e efeitos visuais

## 🎮 Como Usar

### Pelo Mouse/Toque
- Clique nos botões de números para digitar
- Clique nos botões de operadores (+, -, ×, /)
- Clique em **=** para calcular
- Clique em **C** para limpar tudo
- Clique em **⌫** para deletar o último dígito

### Pelo Teclado
| Tecla | Função |
|-------|--------|
| `0-9` | Adiciona número |
| `+` `-` `*` `/` | Operadores |
| `.` | Decimal |
| `Enter` | Calcula resultado |
| `Backspace` | Deleta último dígito |
| `Escape` | Limpa tudo |
